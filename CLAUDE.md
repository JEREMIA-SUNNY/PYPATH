# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

PyPath: a local-only Python learning app (lessons, quizzes, coding exercises checked by real tests, career tracks, interview prep, portfolio projects). Next.js App Router + React + Tailwind v4 + CodeMirror. It runs learner code by spawning a local Python interpreter. Requires Node 20.9+ and Python 3.10+.

`AGENTS.md` warns that this Next.js version has breaking changes: read the relevant guide in `node_modules/next/dist/docs/` before writing Next-specific code.

## Commands

```bash
npm run dev             # http://127.0.0.1:3000 (use 127.0.0.1, not localhost; server binds loopback only)
npm run build && npm start
npm run typecheck       # tsc --noEmit
npm run check:content   # validate all content AND run every exercise's solution/starter through Python
npm run check:content -- strings   # only modules whose id contains "strings"
```

There is no test runner or linter configured. `check:content` is the test suite for course content. Environment variables: `PYPATH_PYTHON` (interpreter path), `PYPATH_DATA_DIR` (progress location, default `data/`).

## Architecture

**Content is files, not a database.** `content/NN-module-id/` holds `module.yaml` (title, summary, icon, section, skills, optional kind/packages), `NN-lesson.md` (gray-matter frontmatter: `title`, `minutes`), `quiz.yaml`, and `exercises.yaml`. The numeric prefix sets order and is stripped to form the id (`03-strings` → `strings`). `content/tracks.yaml` and `content/projects.yaml` define career tracks (lists of module ids) and portfolio projects. `src/lib/content.ts` (server-only) loads everything into the types in `src/lib/types.ts`.

**Exercise grading** (the non-obvious part): `src/lib/python.ts` writes the learner's code to `main.py` (plus `tests.json` in test mode) in a temp dir and spawns `python/harness.py`. The harness runs `main.py` as `__main__`, then execs each YAML test snippet in the same namespace with helpers `__stdout__` and `capture_output(fn, ...)`. The result is returned as JSON on a line prefixed by a random per-run sentinel, which `python.ts` parses out of stdout. Timeout is 10s; output is capped. `scripts/check-content.mjs` re-implements this spawn flow independently, so keep the two in sync if the harness protocol changes. Each exercise needs a `solution` that passes all tests and `starter` that fails at least one.

**API routes** (`src/app/api/{run,python,progress}`): every handler must call `rejectUnlessLocal` from `src/lib/guard.ts` (loopback Host, same-origin Origin, and an `x-pypath: 1` header on writes). This is the security boundary since the API executes arbitrary code. Client calls go through `src/lib/client-api.ts`.

**Progress** lives in a single JSON file (`data/progress.json`, gitignored) managed by `src/lib/progress-store.ts` (atomic writes with Windows rename fallback, corrupt-file backup) and the pure reducer in `src/lib/progress.ts` (`applyEvent`, `normalizeProgress`). The client mutates by sending `ProgressEvent`s, not whole documents.

**UI**: pages in `src/app/` are mostly thin server components that load content and hand it to `*-client.tsx` components in `src/components/` (lesson-client, quiz-player, workspace, playground-client, etc.). Server-only modules import `"server-only"`; fs paths use `/* turbopackIgnore: true */` on `process.cwd()` joins.

## Hosted mode

`NEXT_PUBLIC_PYPATH_MODE=hosted` (see `src/lib/mode.ts`, `npm run build:hosted` / `dev:hosted`) builds a static export (`out/`) with no API routes. Route handlers are named `route.local.ts`; `next.config.ts` only adds `local.ts` to `pageExtensions` in local mode. Progress goes through `src/lib/progress-backend/` (`server.ts` for local, `hosted-store.ts` for file + IndexedDB), gated on load by `components/hosted/progress-gate.tsx`. Code runs via `src/lib/runner/`: `pyodide-core.ts` (shared with `scripts/check-content-pyodide.mjs`) runs the unchanged `python/harness.py`; the browser worker is generated into `public/` by `scripts/prepare-hosted.mjs` (not bundled by Turbopack, because Pyodide rejects classic workers). `content/browser-compat.json` is generated by `npm run check:content:browser`.
